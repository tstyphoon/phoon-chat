# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. 可以傳文字，也可以傳圖片；網址會變成可點的連結
5. 自己送出的訊息可以刪除，刪除後所有人的畫面都會一起消失
6. 往上捲可以看更早的訊息，訊息保留 30 天

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- 深色、淺色、跟隨系統三種外觀，可以手動切換
- 提示音的開關（預設關閉）

## 不需要的
- 註冊、登入
- 私訊、編輯已送出的訊息、表情回應（這一版刻意不做）

## 新增功能

除了「進入、聊天、線上名單、進出提示、斷線重連」這些基本聊天室功能之外，這一版另外做了下面的功能。

### 只影響自己畫面的功能

| 功能 | 說明 | 程式位置 |
|---|---|---|
| 提示音開關 | 頁面在背景時收到別人的訊息會播放提示音。預設關閉，開關的選擇記在自己的瀏覽器 | `src/hooks/useSound.ts` |
| 分頁標題顯示未讀數 | 頁面在背景時，收到別人的訊息會讓分頁標題變成「(3) phoon-chat」，回到頁面後清掉 | `src/hooks/useUnreadTitle.ts` |
| 手動切換外觀 | 深色、淺色、跟隨系統三種，選擇記在自己的瀏覽器；手機上是一顆按鈕依序切換 | `src/hooks/useTheme.ts` |
| 網址自動轉成可點連結 | 訊息裡 `http://`、`https://` 開頭的網址會變成連結，在新分頁開啟。其餘一律當純文字顯示，訊息裡的 HTML 不會被執行 | `src/components/MessageBody.tsx` |
| 往上捲載入更早的歷史訊息 | 一次載入 50 則，往上捲到頂端會自動再載入；看舊訊息時有新訊息進來不會把畫面拉走，只顯示「有 N 則新訊息」按鈕 | `src/components/MessageList.tsx`、`src/hooks/useChat.ts` |
| 圖片預覽與放大 | 選好圖片後送出前先看預覽；收到的圖片點一下可以放大，按 Esc 或點背景關閉 | `src/components/Composer.tsx`、`src/components/Dialogs.tsx` |

### 和所有人即時同步的功能

| 功能 | 說明 | 程式位置 |
|---|---|---|
| 刪除自己的訊息 | 自己送出的文字或圖片，每則旁邊都有刪除按鈕，按下後先跳出確認框。確認後所有人的畫面都會即時消失，圖片檔案也一併刪除。資料庫的規則也限制只能刪自己的，別人的訊息刪不掉 | `src/components/MessageList.tsx`、`src/components/Dialogs.tsx`、`supabase/migrations/20261013000001_messages.sql` |

### 由 Supabase 服務與伺服器端規則提供的功能

| 功能 | 說明 | 程式位置 |
|---|---|---|
| 用 Supabase Storage 傳圖片 | 可以按按鈕選圖、直接貼上、或拖曳進畫面。圖片櫃 `chat-images` 在伺服器端限制單檔 5 MB，只收 JPEG、PNG、GIF、WebP 四種（不收 SVG），而且每個人只能把圖片放進自己的資料夾 | `src/rules/image.ts`、`supabase/migrations/20261013000002_storage.sql` |
| 資料庫觸發器限制發送頻率與防洗版 | 前端會先檢查，但公開金鑰在網頁裡，有人可以繞過畫面直接送資料，所以資料庫的觸發器再檢查一次：每個身分約每秒最多一則；單則內同一個詞重複超過 10 次不能送；30 秒內相同內容送到第 6 次起不能送 | `supabase/migrations/20261013000001_messages.sql` |
| 伺服器端擋保留字代號 | 「系統」「管理員」「客服」「admin」等容易冒充官方的代號，資料庫會拒絕（不分大小寫、全形半形，忽略空白與底線）；也擋看不見的控制字元 | `supabase/migrations/20261013000001_messages.sql` |
| Edge Function 每日清理 | Edge Function 搭配排程（pg_cron），每天台灣時間凌晨 3 點刪除超過 30 天的訊息與圖片 | `supabase/functions/cleanup-expired/index.ts`、`supabase/migrations/20261013000003_cleanup_schedule.sql` |
| 匿名登入加 RLS | 不用註冊，由 Supabase 匿名登入發一個隱形身分。資料庫的 RLS 規則：只能用自己的身分寫入訊息、只能刪除自己的訊息、訊息送出後不能修改、只能讀 30 天內的訊息 | `supabase/migrations/20261013000001_messages.sql` |
