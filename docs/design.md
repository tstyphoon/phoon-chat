# phoon-chat 畫面設計

> 這份文件記錄 `/design` 的設計結果，給下一步用 `/frontend-design` 做前端時對照。
> 畫面清單與行為的依據是 [`architecture.md`](./architecture.md) 第 7 段；這裡只補「長什麼樣子」。
> 設計稿（靜態、不能操作）：https://claude.ai/artifact/AKVCAzcHYaKzSiEyoHUC8a （私人連結，只有建立者能開）

## 1. 設計方向

- 手機優先，電腦版是同一套東西放寬。
- 深色與淺色各一套，預設跟隨系統（架構文件第 1 段）。
- 安靜的冷色調，主色是青藍色；名字用幾種亮度相近的顏色區分，不靠頭像。
- 訊息排版是 Discord 式：全部靠左，不用氣泡；自己的訊息整塊用淡青色底。
- 這個風格是我（Claude）自己決定的，因為需求檔的「風格」欄位沒填。想換方向，改這份文件和設計稿即可。

### 字型

- 內文：Noto Sans TC（400、500、700），後備 `system-ui`。
- 站名 phoon-chat：Space Grotesk 600。
- 時間用 `font-variant-numeric: tabular-nums`，數字等寬不跳動。
- 字級：內文 15px（行高 22px）、代號 14px 粗體、時間與輔助說明 12–13px、進入畫面輸入框 18px、站名 34px（進入畫面）／18px（手機標題列）／22px（電腦側邊欄）。

### 尺寸

- 所有可點的東西至少 44 × 44px（手機）。電腦版滑鼠專用的小按鈕（例如訊息上的刪除）可以小一些。
- 圓角：輸入框 14px、按鈕 12px、訊息輸入框與送出鈕 22px（膠囊形）、圖片縮圖 12px。
- 圖片縮圖：240 × 160px，點一下放大。
- 手機設計寬度 390px；電腦設計寬度 1280px，側邊欄 280px。

## 3. 畫面與元素

設計稿共 7 張。對應 `architecture.md` 第 7 段的每一項如下。

### 進入畫面（稿 1、2）

- 頂端右側：主題三選一（深色、淺色、跟隨系統），選中的有底色，用 `aria-pressed` 標示；手機上是一顆按鈕，點一下依序切換三種。
- 站名（logo 圖形 + phoon-chat）與一句說明：「不用註冊、不用登入。輸入一個代號，就能加入聊天室。」
- 「你的代號」輸入框：預先填入上次使用的代號；下方左邊是規則說明（1 到 12 個字，中文、英文、數字、emoji 都可以），右邊是字數（例如 2 / 12）。
- 「進入聊天室」按鈕：整列寬，高 52px。
- 錯誤提示（稿 2）：輸入框邊框變紅、下方一行圖示加文字，例如「這個代號有人在用了，請換一個」；用 `role="alert"`，輸入框加 `aria-invalid`。
- 頁尾小字：「匿名聊天室．訊息與圖片保留 30 天」。
- 有預填代號時顯示「已自動填入你上次使用的代號」。

### 聊天室：手機（稿 3、4）

由上到下：

1. **標題列**（高 56px）：站名、提示音鈕、主題鈕、「離開」鈕（紅色外框）。提示音鈕預設是關閉的圖示。
2. **連線橫幅**（只在斷線時出現，高 40px，琥珀色）：「連線中斷，重新連線中…」，用 `role="status"`。
3. **人數列**（高 44px，整列可點）：綠點、「12 人在線」、右側箭頭；用 `aria-expanded`。收合時只顯示人數。
4. **在線名單**（展開時）：每列 40px，綠點 + 代號（有顏色），自己加「（你）」；列太多時在框內捲動。
5. **訊息流**：靠底部對齊，內容見第 4 段。
6. **新訊息提示**：右下角膠囊按鈕「有 3 則新訊息 ↓」，位於輸入區上方約 16px，主色實心。
7. **輸入錯誤提示**（有錯誤時）：輸入區上方一條紅底小提示，例如「請不要重複洗版」（送太快時訊息會自動排隊，只有連續狂按到排不下，才會顯示「送太快了，請稍等一下」），圖示加文字，`role="alert"`，幾秒後消失。
8. **字數計數**（接近 500 字時）：輸入區上方右側，例如 `487 / 500`，琥珀色。
9. **輸入區**：圖片鈕（44px 圓）、多行文字框（膠囊形，預設一行）、送出鈕（44px 圓）。文字框空白時送出鈕灰色且不能按。

### 聊天室：電腦（稿 6）

- 左側固定 280px 側邊欄：站名、「12 人在線」與名單、底部依序是提示音鈕（文字「提示音：關閉」）、主題三選一、「離開聊天室」。電腦上名單固定展開，不用人數列。
- 右側是訊息流與輸入區，輸入區左右各留 48px。
- 輸入區上方有圖片預覽卡：64px 縮圖、檔名、大小說明，右側「取消」「送出圖片」。
- 文字框下方一行小字：「Enter 送出，Shift + Enter 換行」。
- 訊息流頂端在載入更早訊息時顯示「載入更早的訊息…」加小轉圈圖示。
- 自己已送出的每則訊息，右側一直有「刪除」鈕（電腦版是淡淡的圖示加文字，滑鼠移上去變清楚；手機版是圖示）。

### 圖片放大檢視（稿 5）

- 蓋滿整個畫面的近黑色背景（`#06090C`），圖片置中、寬度撐滿。
- 右上角圓形關閉鈕（44px，半透明白底）。
- 點背景、按關閉鈕、按 Esc 都能關閉；容器用 `role="dialog"` 與 `aria-modal`。

### 其他狀態（稿 7）

- 按下進入後：按鈕變暗，顯示轉圈與「進入中…」，且不能再按。
- 連不上：警示圖示、「無法連上聊天室」、「請檢查網路後再試一次。」，沒有另外的「再試一次」按鈕，使用者再按一次「進入」就能重試。
- 空狀態：logo 圖形、「這裡還沒有訊息」、「來當第一個開口的人吧。」
- 讀取中：灰色長條骨架 + 「載入最近的訊息…」。
- 分頁標題：沒有新訊息是 `phoon-chat`，在背景收到 3 則是 `(3) phoon-chat`。
- 標題列按鈕：提示音有「關閉（預設）」與「開啟」兩種圖示（開啟時用強調色）；主題有深色（月亮）、淺色（太陽）、跟隨系統（螢幕）三種圖示。手機上主題鈕點一下依序切換三種。

## 4. 訊息的呈現規則

| 項目 | 規則 |
|---|---|
| 一般訊息 | 上方一行：代號（粗體、有顏色）+ 時間（`14:32`，小字、灰色）；下面是內文 |
| 同一人連續的訊息 | 合併成一組，只在第一則上方顯示代號和時間 |
| 自己的訊息 | 整組放在淡色圓角底（圓角 12px）裡，內距上下 8px、左右 12px；代號用強調色。底色向外延伸 12px，讓文字和別人的對齊 |
| 日期分隔線 | 跨日時出現：左右一條細線，中間 `2026年10月13日` |
| 進出提示 | 置中、12px、灰色，例如「小華 加入了聊天室」；跟著訊息一起往上捲，不存入歷史 |
| 網址 | 轉成連結，用連結色，在新分頁開啟（`target="_blank"` 並加 `rel="noopener noreferrer"`） |
| 圖片訊息 | 圖片單獨成一則，240 × 160 的縮圖放在代號與時間下面；整張縮圖是一顆按鈕，游標變放大鏡，`aria-label="放大圖片"` |
| 傳送中 | 自己的訊息內文降到約 60% 透明度，旁邊小字「傳送中…」 |
| 未送出 | 內文降到約 60% 透明度，旁邊紅色可點文字「未送出，點一下重送」，帶重試圖示，點一下用同一個 id 重送 |
| 刪除（手機） | 自己訊息的右側一直有垃圾桶圖示（點按範圍 44px），點了出現確認框：標題「刪除這則訊息？」、說明「刪除後，所有人的畫面上都會消失。」、「取消」和紅色「刪除」兩顆按鈕 |
| 刪除（電腦） | 自己訊息的右側一直有淡淡的垃圾桶圖示加「刪除」文字，滑鼠移上去或用鍵盤移到時變清楚，點了之後同樣出現確認框 |
| 最上方 | 載入到底時顯示「沒有更早的訊息了」（置中、12px、灰色） |

## 5. 無障礙與細節

- 所有可點的東西都是真正的 `<button>`、`<a>`、`<input>` 加 `<label>`，不用 `div` 加點擊。
- 只有圖示的按鈕要加 `aria-label`，例如「提示音：已關閉，點一下開啟」「選擇圖片」「送出」。
- 圖示若只是裝飾，加 `aria-hidden="true"`；圖片縮圖加說明。
- 文字對比：一般文字至少 4.5:1。上表顏色已照此挑選，換色時要重新檢查。
- 錯誤與狀態用「圖示 + 文字」，不只靠顏色。
- 兩種主題下都要檢查：代號顏色、自己訊息的底色、輸入框邊框、停用的送出鈕。
- 手機輸入框不要小於 16px 以免 iOS 自動放大；設計稿裡文字框是 15px，**實作時要改成 16px**。

## 6. 設計稿未涵蓋、實作時要補上的

- 設計稿都是靜態的，沒有動畫。需要做的轉場：名單展開收合、新訊息出現、圖片放大。加動畫時要尊重 `prefers-reduced-motion`（使用者系統設了「減少動態」就關掉）。
- 圖片在設計稿裡是示意圖形，實作時換成真正的圖片；載入失敗時要有一個替代的灰色方塊與文字。
- 沒有畫電腦版的圖片放大、進入畫面電腦版，以及平板寬度。這些沿用手機版的元素，放大後把內容限制在合理寬度（進入畫面表單約 400px、居中）。
- 窄螢幕（寬度小於約 720px）電腦版側邊欄要收成手機版的人數列加標題列。
- 鍵盤操作：Tab 順序依畫面由上到下；名單展開鈕、圖片放大檢視要能用鍵盤開關；放大檢視開啟時焦點要鎖在裡面，關閉後回到原本的縮圖。
- 訊息框的「Enter 送出、Shift + Enter 換行」只套用在有實體鍵盤的裝置；手機的 Enter 是換行，靠送出鈕送出（見 `architecture.md` 7.2）。
